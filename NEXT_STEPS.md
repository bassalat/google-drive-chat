## Quick Wins (Easy to Implement)

1. **Add more MCP tools** (1-2 hours each)
   - `get_folder_contents` - List specific folder
   - `get_recent_files` - Files modified recently
   - `get_starred_files` - Important files

2. **UI improvements** (1-3 hours)
   - Add file icons for different types
   - Show typing indicators
   - Add loading skeletons

3. **Better error messages** (30 mins)
   - User-friendly error display
   - Retry mechanisms

4. **Configuration file** (30 mins)
   - `config.yaml` for settings
   - Environment-specific configs
